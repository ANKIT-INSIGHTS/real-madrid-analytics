# Real Madrid Performance Analytics 2025-26

Interactive dashboard built with React + Recharts.

## Run locally
```
npm install
npm run dev
```
Then open the URL it prints (usually http://localhost:5173).

## Deploy to GitHub Pages
This repo includes a GitHub Actions workflow (`.github/workflows/deploy.yml`)
that builds and deploys automatically on every push to `main`. See the
step-by-step guide for the one-time setup.
